# ui-office-studio

白棚工位办公室：**成片层 + 百分比热区 + useAgents**。  
规格：[OFFICE-STUDIO-SPEC.md](../../docs/OFFICE-STUDIO-SPEC.md)。

## 成片素材

| 层 | 现状 |
|---|---|
| 默认 | 自有 SVG 工位棚（`ui/stage-film.js`）：2×3 桌椅显示器、短角剪影、provider 领色、工作/待命/休假态与屏光 |
| 可选 | `ui/assets/office-loop.mp4` + `office-poster.jpg`（**仅自有**；禁止第三方入仓） |

选型板 Demo D 的 Marvis 成片只做 UX 对照，不进本插件。

导航标题：**工位棚**；harness：`/api/ui/ui-office-studio/harness.html`。
