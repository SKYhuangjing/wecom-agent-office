> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 DESIGN v3 §14 M3——Web UI（Shell+SDK+页面插件：workbench 五页+办公室 3D v2）+ 运维加固（launchd/孤儿防护/遗留 minors）+ 按 §12 逐 bot 生产切换上线 + 总收官。

**Architecture:** web/ = 薄 Shell（导航/路由/主题/window.WAO 注入）+ SDK（useAgents/useTimeline/useSSE/api）；一切视图皆页面插件（无构建 ES Module、禁 JSX/bare import、React 从 window.WAO 取）；ui-workbench 与 ui-office3d 是内置页面插件；内核静态托管 web/dist 与各插件 ui/（/api/ui/<owner>/）+ 同源 harness。切换=已授权裁定机制（清空旧 bots.json+SIGTERM 旧桥→新服接管→launchd KeepAlive）。

**Tech Stack:** React 18 vendored UMD（web/vendor/，离线）；esbuild（devDep）打包 Shell/SDK 到 web/dist（产物提交）；页面插件源码无构建直用。

**Spec:** docs/DESIGN.md v3 §9（Web UI）/§12（切换，按裁定执行）/§13/§14；HANDOFF.md M3 入口两条 slipped minors。

## Global Constraints（M3 全局）

- 沿用 M1/M2 全部约束；内核改动最小化（静态托管/页面发现属内核 HTTP 壳既有职责范畴，超出则先停下回报）
